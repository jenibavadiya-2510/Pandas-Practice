# Pandas-Practice
Learning and practicing Pandas in Python for data analysis, data cleaning, and data manipulation.

## About This Repository
This repository contains my Pandas practice programs and notebooks using Python. It documents my learning journey in data manipulation, data cleaning, and exploratory data analysis.

## Topics Covered
- Introduction to Pandas
- Series and DataFrames
- Data Selection and Filtering
- Adding and Removing Columns
- Handling Missing Values
- Removing Duplicate Records
- Data Type Conversion
- Sorting and Ranking
- GroupBy and Aggregation
- Merging, Joining, and Concatenation
- Date and Time Operations
- Pivot Tables and Crosstabs
- Basic Exploratory Data Analysis (EDA)

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Visual Studio Code

## Installation

Install the required libraries:

```bash
pip install pandas numpy jupyter
```

## How to Run
1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Install the required libraries.
4. Open any `.ipynb` notebook.
5. Run the cells to explore the examples.

## Learning Goals
- Clean and prepare datasets.
- Handle missing and duplicate values.
- Filter, transform, and analyze data.
- Group and summarize data.
- Build a foundation for Data Analyst projects.
